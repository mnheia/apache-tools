# apache-tools
Bash utilities for Apache log analysis, visitor statistics, IP resolution and MPM health monitoring.

## Scripts

### apache-visitors-range.sh

Analyzes Apache access logs over a date range, including plain, gzip and xz-rotated logs. Produces per-domain likely-human page views and estimated unique visitors, daily and monthly trends, top pages, known crawler statistics, suspicious scanner activity, probe paths, HTTP errors and top client IPs. No external analytics service or third-party Python modules are required.

Page views are successful HTTP 200 GET requests to page-like URLs after filtering. Estimated visitors are unique **IP address + User-Agent** combinations, not verified people. These figures are approximate, especially for JavaScript-routed sites and automated browsers.

```bash
./apache-visitors-range.sh
./apache-visitors-range.sh 2026-10-01 2026-10-27 /var/log/apache2

EXCLUDE_DOMAINS="box01.sovec.si,fwl01-mb.sovec.si" \
  ./apache-visitors-range.sh 2026-04-27 2026-10-27 > apache-public-report.txt
```

Environment configuration:

| Variable | Default | Purpose |
|---|---|---|
| `FILTER_BOTS` | `1` | Exclude recognized automated User-Agents from visitor totals |
| `FILTER_SUSPICIOUS` | `1` | Exclude probe requests and behavioral scanners from visitor totals |
| `FILTER_RESEARCH_SCANNERS` | `1` | Exclude documented research scanning networks |
| `EXCLUDE_PRIVATE_IPS` | `1` | Classify private/non-global source addresses as internal |
| `EXCLUDE_STATIC` | `1` | Exclude static files from filtered request counts |
| `ONLY_STATUS_2XX_3XX` | `1` | Filter successful requests; page views remain HTTP 200 GET only |
| `EXCLUDE_DOMAINS` | empty | Comma- or whitespace-separated vhosts to omit entirely |
| `SCANNER_IPS_FILE` | empty | Optional local file of IPs/CIDRs to exclude from visitor statistics |
| `TOP_IPS` | `25` | Top likely-human IPs per domain |
| `TOP_PAGES` | `10` | Top page paths per domain |
| `TOP_SUSPICIOUS` | `20` | Top suspicious addresses |
| `TOP_ERRORS` | `10` | Top probe and eligible 404 paths |
| `DAILY_BY_DOMAIN` | `0` | Include daily per-domain breakdown |

Behavioral scanner classification is evaluated per source IP per day to avoid excluding an IP's entire six-month history after one suspicious day. The provided research-network list is used **only for analytics classification**. These scripts do not alter Apache, Fail2Ban or MikroTik firewall settings.

### apache-unique-visitors-today.sh

Runs the same parser and filters as the range script for one day; includes the same statistics sections. The original date format remains accepted, and ISO dates are also supported.

```bash
./apache-unique-visitors-today.sh
./apache-unique-visitors-today.sh 27/Oct/2026
./apache-unique-visitors-today.sh 2026-10-27 /var/log/apache2
```

For reverse DNS/ASN enrichment, use the separate IP resolver rather than `RESOLVE_DNS` on the daily script.

### resolve-apache-top-ips.sh

Reads a report generated by `apache-visitors-range.sh` and extracts top likely-human IPs, suspicious IPs, or both. Optionally enriches IPs with reverse DNS and Team Cymru ASN details.

```bash
./apache-visitors-range.sh > apache-report.txt
./resolve-apache-top-ips.sh apache-report.txt

SOURCE=suspicious TOP=25 ./resolve-apache-top-ips.sh apache-report.txt
SOURCE=both TOP=10 OUT=/tmp/apache-ips.tsv ./resolve-apache-top-ips.sh apache-report.txt
```

Options: `SOURCE=human|suspicious|both` (default `human`), `TOP=20`, `OUT=resolved-top-ips.tsv`, `RESOLVE_DNS=1`, `LOOKUP_ASN=1`, `DNS_TIMEOUT=2`. Set `RESOLVE_DNS=0 LOOKUP_ASN=0` for offline extraction. The resolver uses IPv4/IPv6 parsing and preserves the source category. Country and GeoIP enrichment are intentionally not included in the revised resolver.

### check-apache-mpm.sh
Checks Apache service state, configuration syntax, active MPM settings, theoretical worker capacity, recent worker-saturation messages, live `mod_status` worker usage and basic memory consumption.

The output uses Nagios-style exit codes:

- `0` OK
- `1` WARNING
- `2` CRITICAL

By default the script queries:

```text
http://127.0.0.1/server-status?auto
```

Override it with `STATUS_URL` when required.

Example:

```bash
WARN_PCT=80 CRIT_PCT=90 ./check-apache-mpm.sh
```

## mod_status configuration
`mod_status.conf.example` contains a minimal configuration for `check-apache-mpm.sh`.

On Debian/Ubuntu, for example:

```bash
cp mod_status.conf.example /etc/apache2/conf-available/mod_status.conf
a2enmod status
a2enconf mod_status
systemctl reload apache2
```

The example permits localhost access only. Add trusted monitoring networks explicitly if remote access is required. Avoid exposing `/server-status` publicly.

## Requirements
Depending on the script:

- Bash
- Apache/httpd
- GNU core utilities and `date` (used for the default six-month range)
- Python 3 standard library for visitor analysis and IP report extraction
- `gzip` and `xz` support via Python for rotated access logs
- `curl` for `check-apache-mpm.sh`
- `dig` or another resolver for reverse-DNS enrichment
- optional `mmdblookup` with a GeoLite2 City database

## Privacy
Apache reports may contain visitor IP addresses, hostnames and requested domains or paths. Review generated reports before sharing them externally.
